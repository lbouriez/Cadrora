# Optional demonstration content

The public wedding gallery `lumiere-et-promesses` includes five fictional moments: preparations, ceremony, terrace reception, sunset, and dance. Each has thumb, medium, and large WebP variants tracked in the seed manifest and D1 records.

These WebP files are original, AI-generated demonstration images created for Cadrora. They do not depict real clients and are not part of the static website build. When `CADRORA_SEED_DEMO=true`, the release script uploads them to the deployment's private `MEDIA_BUCKET` and applies the idempotent D1 records in `demo.sql` before deploying the Worker. The seed also sets fictional phone, email, address, and service area in D1 only while the site-settings row is untouched; it never replaces owner-edited or intentionally cleared contact values.

The public sample gallery is `lumiere-et-promesses`. The protected sample is `instants-en-famille`, with the deliberately public disposable password `cadrora-demo`. The face-search gallery contains nineteen images. The five `ai-demo-11` through `ai-demo-15` scenes feature the fictional guest Malik; `ai-demo-16` and `ai-demo-17` are vertical solo photographs of Amelia; `ai-demo-18` and `ai-demo-19` are vertical photographs of another distinct fictional guest, Nora. Their sort keys interleave the portraits with the older landscape photos to exercise the responsive mosaic and carousel. The seven Malik/Nora photos are negative controls against the Amelia and Daniel test portraits. Capture timestamps place several of them within five minutes of direct matches so the nearby carousel demonstrates temporal context without mislabelling those photos as face matches. The tracked JPEG import fixture is derived from `ai-demo-11` and carries its `18:02 UTC` capture instant in real EXIF. Disable demo seeding for a real photographer deployment and publish real contact values in Admin Site settings before launch.

The four vertical images were created with the built-in image-generation tool, then encoded as 320 × 480, 640 × 960, and 1024 × 1536 WebP variants without source metadata. The final prompt set was: Amelia alone by the outdoor wedding terrace in a cream blazer (`16`), Amelia alone on the garden path in the same outfit (`17`), a distinct fictional copper-haired guest Nora alone by the terrace in a green dress (`18`), and Nora alone seated in the garden in the same dress (`19`). All four prompts specified a photorealistic 2:3 documentary wedding photo, natural golden-hour light, one clear face, and no text, logo, or watermark. Amelia's public test portrait was the identity reference for both Amelia photos; `18` was the identity reference for `19`. The committed WebP variants are the deployable assets; the image-generation output directory is not part of the project.
